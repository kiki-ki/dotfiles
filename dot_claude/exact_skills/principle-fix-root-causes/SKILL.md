# principle-fix-root-causes

デバッグでは症状を直さない。根本原因まで辿り、そこで直す。症状への対処は積み重なり、そのたびにシステムは追いにくくなるうえ、本当のバグは残る。

- まず再現する。
- 根本原因に着くまで「なぜ」を繰り返す。
- ガードを足さない。クラッシュを黙らせるための nil チェックは症状への対処だ。
- 回避策の説明に段落ひとつ分のコメントが要るなら、直すべきはコメントではなくコードだ。
- 見つけた 1 箇所だけでなく、同じパターンを grep して全部直す。
- 行き詰まったら推測せずに計測する。ログを足し、実際のエラーを読む。

## 再起動の後だけ壊れるとき

コードより先に、古い永続状態を疑う。設定ファイル、キャッシュ、ロックファイル、シリアライズされた状態だ。状態ファイルを消して直るなら、状態の検証を直すことを優先する。
