# 日本語の文の規則

## 文の長さと構造

- 一文に一つのことだけを書く。二つのことを言っている文は切る。目安は 80 字、読点は 3 つまで。
- 逆接でない「が」で文をつながない。「A だが、B」は A と B が対立するときだけ使う。
- 主語と述語を近づける。長い修飾語は前に、短い修飾語は後ろに置く。
- 修飾語がどこに係るかで二通りに読める語順にしない。「〜ない」「〜だけ」は、係る語の直前に置く。
- 二重否定を使わない。「〜しないわけではない」は肯定で書き直す。
- 同じ助詞を 1 文の中で続けない（「A の B の C の」など）。

## 冗長な言い回し

- 「〜することができる」→「〜できる」
- 「〜を行う」「〜を実施する」→「〜する」
- 「〜という形で」「〜という点で」「〜的な」→ 削るか、具体的に言う
- 「〜していく」「〜してまいります」→「〜する」
- 同じ主張を言い換えて繰り返さない。一つの主張は一度だけ書く。

## 主語と語

- 誰が何をするかを書く。「〜が確認された」ではなく「CI が〜を確かめる」。受け身は、行為者が分からないときか関係ないときだけ使う。
- 「これ」「それ」「この」が指すものを一つに決める。迷ったら名詞を繰り返す。
- 同じものは、文書の最後まで同じ名前で呼ぶ。言い換えは、別のものがあるように読ませる。
- 普段使う言葉で書く。造語や比喩は使わず、使うなら初出で意味を書く。

## 確かさ

- 本文の根拠で確定していることは言い切る。確かめていないこと、推定、仮定は、その不確実さを残して書く。
- 因果を書くときは、なぜそうなるかを一文で添える。
- 「A ではない」と否定するときは、否定する内容をはっきり書き、根拠を一文添える。
- 「必ず」「すべて」は、本当にそうだと確かめたときだけ使う。

## 表記

- 書き込む先の既存の表記に合わせる。手がかりがなければ次の既定に従う。
- 英数字と日本語の間に半角スペースを入れる。
- 句読点は「、」「。」。感嘆符と疑問符は使わない。
- 形式名詞と補助動詞はひらがなで書く（こと、とき、もの、ところ、ください、いる、みる、など）。
- 数は算用数字で書く。「一つ」「一度」のように、数えていない慣用表現は漢数字のままにする。
- ダッシュ（——）を地の文で使わない。補足は括弧に入れるか、文を分ける。
- スラッシュで「A/B」とまとめない。「A と B」「A または B」と書く。
