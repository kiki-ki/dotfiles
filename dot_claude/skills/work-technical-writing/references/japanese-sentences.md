# 日本語の文の規則

書き込む先の既存の表記があればそれに合わせる。

- 一文に一つのことだけを書く。目安は 80 字、読点は 3 つまで。
- 逆接でない「が」で文をつながない。「設定を読むが、不正なら終了する」は 2 文に分ける。
- 主語と述語を近づける。長い修飾語は前に置き、名詞の前に修飾を 2 つ以上重ねたら文を分ける。
- 「〜ない」「〜だけ」は係る語の直前に置き、二通りに読める語順にしない。二重否定は肯定に直す。
- 同じ助詞を続けない（「A の B の C の」）。
- 同じ主張を言い換えて繰り返さない。
- 動作を名詞にしない。「設定の変更を行う」「〜の実施」「〜化を図る」は「設定を変える」のように動詞で書く。
- 「〜することができる」は「〜できる」、「〜していく」は「〜する」にする。「〜という形で」「〜的な」は削るか具体的に言う。
- 誰が何をするかを書く。「設定値が検証される」は「`config.Load` が設定値を検証する」にする。受け身は行為者が分からないか関係ないときだけ使う。
- 事実や結果を主語にして「示す」「もたらす」と書かない。「この結果は〜を示している」は「この結果から〜と分かる」にする。
- 明らかな主語（「私たちは」）を毎文書かない。「〜させていただきます」を重ねない。
- 「これ」「それ」が指すものを一つに決める。同じものは最後まで同じ名前で呼ぶ。
- 日本語で言えるカタカナ語、造語、比喩は使わない。使うなら初出で意味を書く。
- 因果には理由を一文添える。否定するときは根拠を添える。「必ず」「すべて」は確かめたときだけ使う。
- 表記の既定: 英数字と日本語の間に半角スペース。句読点は「、」「。」で、感嘆符と疑問符は使わない。形式名詞と補助動詞はひらがな（こと、とき、いる、みる）。数は算用数字で、「一つ」「一度」のような慣用は漢数字。「A/B」は「A と B」「A または B」と書く。
